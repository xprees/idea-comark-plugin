Reports text after a block component opener's content and attributes.

An opener line consists of the component name, optional [content] and optional {attributes}, in this order. Comark silently drops anything that follows, so it never shows up on the rendered page.

Example:


::alert{type="info"} Read this first
::

::badge{color="green"}[New]
::

The quick-fix removes the ignored text. When the ignored text is [content] written after the attributes, another quick-fix moves it before them: ::badge[New]{color="green"}.
