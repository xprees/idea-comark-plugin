Reports content that Nuxt Studio would change when it saves the file, and that Reformat Code therefore leaves as written in the Nuxt Studio and Custom styles (Settings | Editor | Code Style | Comark | Style). The inspection is active only in these styles.

Examples: raw HTML (Studio turns it into components), HTML comments (dropped), reference-style links (inlined), link reference definitions (deleted), table column alignment (dropped), code fence line highlights, heading {#id} attributes (dropped or escaped), YAML comments in front matter or props (dropped), components inside list items (moved out of the list). The message says what Studio would do. The first line of the block is highlighted.

A weaker note, Nuxt Studio may rewrite this, marks blocks Reformat Code wrote without being able to check them against Studio's database path (the save of a document Studio opened from Nuxt Content), and front matter whose injected title or description may come from a block kept as written.

Quick-fixes:

  • Remove column alignment: writes the table's delimiter row without colons, the way Studio keeps it.
  • Remove the heading id: removes the {#id} Studio would drop.
  • Suppress for this block: puts <!-- @formatter:off --> and <!-- @formatter:on --> around the block (the markers set in Code Style | Formatter when they are enabled). Blocks between these markers are not reported. Reformat Code honours the markers only when they are enabled in the code style settings. Note that Studio itself still changes the block, and drops the comments.
