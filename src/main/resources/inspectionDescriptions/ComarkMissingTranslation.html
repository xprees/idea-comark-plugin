Reports a localized content page that has no translation in some locale of its group.

Localized content keeps one directory per locale next to each other (content/pages/en/, content/pages/cs/). A page's translation is the page at the same path in the other locale's directory, else the page that a front matter key (counterpart by default) or a string map in content.config.ts pairs it with.

The quick fix creates the missing translation as a copy of the page. Locales and front matter keys are set in Settings | Languages & Frameworks | Comark | Translations.
