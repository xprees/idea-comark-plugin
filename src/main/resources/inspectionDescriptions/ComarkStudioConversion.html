Reports emoji shortcodes such as :rocket: and HTML character references such as &copy; or &#169; that Nuxt Studio replaces with the characters themselves when it saves the file. Active in the Nuxt Studio and Custom styles (Settings | Editor | Code Style | Comark | Style).

The quick-fix writes what Studio writes: the emoji or character, or an escape where the character means something in Markdown (&lt; becomes \<). Shortcodes Studio doesn't know, and text in code, link destinations, HTML, front matter and props are not reported.
